# Smart Task Manager
## ایده و هدف
این برنامه یک نرم‌افزار ساده برای مدیریت وظایف روزانه است. کاربر می‌تواند وظایف خود را همراه با توضیحات، میزان اهمیت و Deadline ثبت کند و وظایف بر اساس اولویت و وضعیت نمایش داده می‌شوند.

هدف پروژه ایجاد یک نمونه ساده از یک سیستم مدیریت وظایف و بررسی نحوه استفاده عملی از هوش مصنوعی در فرآیند توسعه نرم‌افزار بوده است.

## ابزارهای هوش مصنوعی

در فرآیند توسعه از **ChatGPT** استفاده کردم.

هوش مصنوعی در بخش‌های زیر به من کمک کرد:

* پیشنهاد ساختار اولیه پروژه
* ایجاد نمونه اولیه برخی بخش‌های کد
* پیشنهاد ساختار Model و Form در Django
* بررسی و پیدا کردن خطاهای احتمالی
* پیشنهاد روش‌های ساده‌تر برای پیاده‌سازی
* کمک در نوشتن مستندات پروژه

## بخش‌هایی که خودم انجام دادم

ساختار نهایی پروژه را بررسی و متناسب با نیاز پروژه اصلاح کردم.

همچنین کدهای تولیدشده توسط AI را مستقیماً قبول نکردم و آن‌ها را بررسی، اجرا و تست کردم. بخش‌هایی مانند منطق اولویت‌بندی وظایف، ساختار نهایی Viewها و نحوه نمایش اطلاعات را بررسی و در صورت نیاز اصلاح کردم.

## اعتبارسنجی خروجی AI

برای بررسی خروجی AI، کدها را در محیط واقعی پروژه اجرا کردم و رفتار آن‌ها را بررسی کردم.

همچنین در مواردی که درباره یک راه‌حل اطمینان نداشتم، آن را با مستندات Django مقایسه و به‌صورت عملی تست کردم.

## نحوه اجرای پروژه

### پیش‌نیازها

- Docker
- Docker Compose

### اجرای پروژه

ابتدا Repository را Clone کنید:

git clone https://github.com/mohamad-karimi/Smart-Task-Manager.git

سپس وارد پروژه شوید:

cd Smart-Task-Manager

کانتینرها را Build و اجرا کنید:

docker compose up --build

در یک ترمینال جدید، Migrationها را اجرا کنید:

docker compose exec backend python manage.py migrate

سپس پروژه را از طریق آدرس زیر باز کنید:

http://127.0.0.1:8000/
## نتیجه

این پروژه یک نمونه ساده از استفاده هدفمند از AI در فرآیند توسعه نرم‌افزار است. هدف اصلی این بود که AI در نقش یک ابزار کمکی برای تحقیق، تولید اولیه، بررسی و رفع خطا استفاده شود و تصمیم‌گیری و اعتبارسنجی نهایی توسط توسعه‌دهنده انجام شود.
